# quiksee_vendor_app

QuikSee Vendor App — sellers manage catalog, orders, POS, delivery, wallet, and shop.

## Flutter SDK : 3.41.9

## Order flow

1. Customer places an order  
2. Vendor receives the order in the app  
3. Vendor Accepts and prepares the order  
4. Order status moves through processing / out for delivery / delivered  
5. Delivery man handles fulfillment after vendor acceptance
